## Inprocode
![inprocode image](https://github.com/user-attachments/assets/8b83253d-f001-4169-ac7b-9b10ce5b2930)

¡Welcome to the Inprocode App! This React app allows expense management and visualization. Daily expenses, percentage changes, and data can be viewed in charts. It integrates charts with Charts.js and supports multiple languages ​​through the i18n library. Unit testing has also been performed with vitest.


## Features

- **Responsive Design: Built with Tailwind CSS and Flowbite to ensure a sleek and responsive UI.
- **Modular Components: Uses reusable React components for maintainability tries to aply SOLID bases.
- **State Management: State is managed using Context for scalability.
- **Multi-language Support: Integrated with i18n for localization.
- **Data Visualization: Interactive charts and data representation using Charts.js.
